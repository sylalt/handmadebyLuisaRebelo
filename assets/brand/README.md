# LUISA London brand assets

Created to match the website's existing visual direction: ivory **#f7f4ec**, deep green **#073f34**, muted gold **#a58c60**, editorial serif lettering, and quiet textile details.

## Files

- **Primary logo:** the current site wordmark at [../luisa-logo.png](../luisa-logo.png), supplied as the main LUISA mark.
- **Secondary logo:** [secondary-lockup.svg](secondary-lockup.svg), a stacked LUISA / LONDON lockup for square or compact placements.
- **Monogram:** [monogram-ll.svg](monogram-ll.svg), an LL seal for labels, favicons, tags, and social avatars.
- **Patterns:** [pattern-crochet-chain.svg](pattern-crochet-chain.svg) and [pattern-botanical-lattice.svg](pattern-botanical-lattice.svg), seamless repeat tiles for packaging, cards, and backgrounds.
- **Texture:** [texture-woven-ivory.svg](texture-woven-ivory.svg), a subtle woven surface tile for large background areas.

The SVG files are editable and scale without loss. Their background colours can be changed in the source if needed.
